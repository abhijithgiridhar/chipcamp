Your sketch

Put it on the robot

  1. Press Copy code (the big button, not by selecting the text) or Download .ino.
  2. Open the Arduino IDE and make a new sketch. Select everything (Ctrl/⌘ + A) and paste.
  4. Tools → Port: pick the USB port, then press Upload ➜
  5. Open Tools → Serial Monitor at 9600 baud to see anything the robot prints.

Error says "undefined reference to setup and loop"? The paste was not the whole sketch. Press Copy code again and paste over everything.

📤 Upload desk

Facilitator only. Click an ID to download the tested Chip Bot sketch. Every ID is the same code. Open it in the Arduino IDE and upload it to the robot, then show the class what it does.

Board: Arduino Nano (Processor: ATmega328P, try Old Bootloader if the upload fails). This sketch needs the OttoDIYLib library on this laptop (Sketch, Include Library, Add .ZIP Library, or the Library Manager). Reloading the page makes a fresh set of IDs.
