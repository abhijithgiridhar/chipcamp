Your sketch

Put it on the robot

  1. Press Copy code.
  2. Open the Arduino IDE and make a new sketch. Select everything (Ctrl/⌘ + A) and paste.
  4. Tools → Port: pick the USB port, then press Upload ➜
  5. Open Tools → Serial Monitor at 9600 baud to see anything the robot prints.
